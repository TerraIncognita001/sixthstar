Privacy Policy

Last updated: 16 November 2026

This policy covers "Sixth Star uploader", a private tool used only by the owner of the Sixth Star YouTube channel to upload that channel's own videos.

What the tool accesses

The tool uses YouTube API Services. After the channel owner signs in with Google, it can upload videos to the owner's channel and read basic information about that channel and its videos (channel name, video titles, view counts). It accesses no other Google data.

What is stored

The Google access token is stored only on the owner's own computer. It is not sent to any server other than Google's, and it is not shared with anyone. The tool has no other users, so it collects no personal data from visitors or viewers. This website uses no cookies and no analytics.

Revoking access

The owner can remove the tool's access at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the token file from the computer has the same effect for the tool.

YouTube and Google

By using the tool the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions about this policy: write through the Sixth Star channel on YouTube (contact details are on its About page).
